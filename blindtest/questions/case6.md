# 盲测问卷 · 第六案（二十年的一个签名）

【玩家须知】
- 你是一款阴间档案推理游戏的玩家，任务是复核案卷，找出卷面里互相矛盾的材料并提交"指错"
- 材料分三类：【文书】= 阴阳两界的官方档案；【灰迹】= 现场残留勘验所得；【口述】= 死者魂魄的自述（其记忆可能被执念扭曲，但魂魄不会故意撒谎）
- 部分【口述】/【灰迹】在游戏内需花行动力调取；本测试假定你已全部阅毕

【作答要求】
1. 找出所有值得提交"指错"的两两组合（每组合两条材料），宁缺毋滥也照实列不确定项
2. 每个组合给出三行：
   - 推理链：引用原文关键词说明为什么这俩对不上
   - 分类：A类·两源互斥（同一件事说法冲突，需改判）/ B类·时间错位（两边各自都对，只是说的不是同一件事/同一时间，不构成冤情）/ C类·无实质关联
   - 确定度：高 / 中 / 低
3. 禁止使用卷面之外的任何设定或脑补

【案情简介】
例行复核：近五年七份已结卷宗，"复核通过"章全部出自同一只手。
你要求当庭比对——这一案，你碰的是判官的公正性。

【卷面材料（共6条）】
1.【文书】七卷复核记录（例行抽卷）："近五年，七份已结卷宗的复核通过章，比对出自同一只手。七卷原判各异，卷龄俱近，复核章同式。"记录附七卷抄目，纸色不一。
2.【灰迹】墨色勘验：七枚复核章笔势相同，墨色不一：三枚墨旧如二百年前陈墨，四枚墨新如昨日研的。同一只手，两种岁月——卷宗立卷不过五年，三枚的墨却旧得像二百年前研的。
3.【口述】老书吏口述："那枚章是岳判官常用的。卷宗递上去，回来就盖好了——他从不亲自动手。三百年都是这样，规矩。那枚章的墨色，三百年一贯。"
（他说"规矩"两个字时，魂焰纹丝不动。他是真信。）
4.【文书】深层调卷记录：复查二十年前旧档：又得同式复核章九卷。复核记录的年限，不止五年——同一只手，从二十年前就在盖。
（你把五年的七卷和二十年的九卷并排摊开。题名里的"二十年"，是这么来的。）
5.【文书】判官职牒：职牒："判官岳景明。"笔迹存档附录式样七份，与七卷复核章逐一相合。
（架阁库的老吏说：判官职牒，向来只记名姓笔迹——哪一任都不记年限。）
6.【灰迹】程序勘验：调七卷归档底账：其中三卷的"复核通过"日期，早于原判归档日期——复核在原判之前。
果在因前。
