# 盲测问卷 · 第四案（临时处的石匠）

【玩家须知】
- 你是一款阴间档案推理游戏的玩家，任务是复核案卷，找出卷面里互相矛盾的材料并提交"指错"
- 材料分三类：【文书】= 阴阳两界的官方档案；【灰迹】= 现场残留勘验所得；【口述】= 死者魂魄的自述（其记忆可能被执念扭曲，但魂魄不会故意撒谎）
- 部分【口述】/【灰迹】在游戏内需花行动力调取；本测试假定你已全部阅毕

【作答要求】
1. 找出所有值得提交"指错"的两两组合（每组合两条材料），宁缺毋滥也照实列不确定项
2. 每个组合给出三行：
   - 推理链：引用原文关键词说明为什么这俩对不上
   - 分类：A类·两源互斥（同一件事说法冲突，需改判）/ B类·时间错位（两边各自都对，只是说的不是同一件事/同一时间，不构成冤情）/ C类·无实质关联
   - 确定度：高 / 中 / 低
3. 禁止使用卷面之外的任何设定或脑补

【案情简介】
死者 老陈，城西石匠，殁年六十一。原判：九月初三殁。误捕积件，恩结——准提前入轮回，配享双份祭飨。

其妻张氏，先亡三年，案悬未结，现居临时处陪押。
你要复核的，是一桩已"恩结"的积压件——判官用印，恩例可查。

【卷面材料（共6条）】
1.【文书】临时处结案批文："老陈，城西石匠，殁于九月初三。误捕积件，依《误捕补偿例》恩结：准提前入轮回，配享双份祭飨。"判官朱印完好，笔迹工整。批文日期：三年前。
2.【灰迹】城西石坊工籍：石坊工籍："老陈，九月初三至初十，点工如常，凿碑一方未讫。"墨线弹了一半的碑还立在坊里，署期九月初三。
3.【口述】老陈口述·一："我没死。卷上写我九月初三殁——那天我在坊里凿碑，墨线弹到一半。跟我同名的是城东老陈，病了半年……初五没的？还是初六？听说的事，记不真。"
4.【口述】老陈口述·二："我婆娘前年走的——前年，还是大前年？这地方的日子，数不清了。她反正走在前头。她的案子能不能也批了——不是做夫妻，是做兄妹。她在城南的坟，是借邻帮我看——我这双手，出不了临时处。"
（说到"兄妹"两个字，他的魂焰稳得反常。他想清楚了才说的。）
5.【口述】张氏口述："我是正路来的，殁了三年，案子排到现在还没批。他一个错抓的，倒先'恩结'了——恩结的批文贴出去三年，人还关在临时处。"
（她说话不急。三年，够把不急学会。）
6.【文书】城东勾录：生死簿城东册："老陈，殁于九月初五，病殁。"墨迹工整。城东的册子，勾的是城东的人。
