# 盲测问卷 · 第三案（一间房两个人半箱竹简）

【玩家须知】
- 你是一款阴间档案推理游戏的玩家，任务是复核案卷，找出卷面里互相矛盾的材料并提交"指错"
- 材料分三类：【文书】= 阴阳两界的官方档案；【灰迹】= 现场残留勘验所得；【口述】= 死者魂魄的自述（其记忆可能被执念扭曲，但魂魄不会故意撒谎）
- 部分【口述】/【灰迹】在游戏内需花行动力调取；本测试假定你已全部阅毕

【作答要求】
1. 找出所有值得提交"指错"的两两组合（每组合两条材料），宁缺毋滥也照实列不确定项
2. 每个组合给出三行：
   - 推理链：引用原文关键词说明为什么这俩对不上
   - 分类：A类·两源互斥（同一件事说法冲突，需改判）/ B类·时间错位（两边各自都对，只是说的不是同一件事/同一时间，不构成冤情）/ C类·无实质关联
   - 确定度：高 / 中 / 低
3. 禁止使用卷面之外的任何设定或脑补

【案情简介】
死者 秦孺人，私塾师之妻，殁年三十九。原判：无诉自殁，免于轮回，就地散录。其女申诉：母亲生前手抄竹简半箱，被邻人张氏以"废纸"名义收走变卖。张氏称：收的是自家亡夫遗物。一间房，两个死者，半箱竹简——你要判的，是竹简上谁的手。

【卷面材料（共6条）】
1.【文书】张氏收据：张氏立据："收废纸半箱，付钱三十文。"日期八月廿三。字据按了指印。
2.【口述】秦孺人口述·一："竹简是我的手抄。我眼睛坏了以后，抄一卷要歇三次。张家男人来借书那回，我数过——箱里是四十七卷。"
3.【灰迹】竹简残印：竹简残片三方，简尾各有一枚小印"秦氏手抄"。印文与张氏收据上的指印，不是同一双手。
4.【口述】张氏口述："废纸是我男人攒的。他生前也抄书——他抄的书，跟这箱子里的，我不认得字，分不出。"（她说"分不出"时魂焰很稳。她真分不出。）
5.【灰迹】书肆进账底簿：书肆底簿："八月廿四，收竹简四十七卷（张氏废纸转售），付张氏钱二百文。"卷数与秦孺人口述吻合——四十七卷。
6.【文书】张氏亡夫遗物清单：张家遗物清单（殁于八月初九）："抄本竹简二十三卷。"张家的竹简是二十三卷，不是四十七卷。

现在给出你的全部"指错"组合。
