# 盲测问卷 · 第二案（同名同姓）

【玩家须知】
- 你是一款阴间档案推理游戏的玩家，任务是复核案卷，找出卷面里互相矛盾的材料并提交"指错"
- 材料分三类：【文书】= 阴阳两界的官方档案；【灰迹】= 现场残留勘验所得；【口述】= 死者魂魄的自述（其记忆可能被执念扭曲，但魂魄不会故意撒谎）
- 部分【口述】/【灰迹】在游戏内需花行动力调取；本测试假定你已全部阅毕

【作答要求】
1. 找出所有值得提交"指错"的两两组合（每组合两条材料），宁缺毋滥也照实列不确定项
2. 每个组合给出三行：
   - 推理链：引用原文关键词说明为什么这俩对不上
   - 分类：A类·两源互斥（同一件事说法冲突，需改判）/ B类·时间错位（两边各自都对，只是说的不是同一件事/同一时间，不构成冤情）/ C类·无实质关联
   - 确定度：高 / 中 / 低
3. 禁止使用卷面之外的任何设定或脑补

【案情简介】
城东有两名"陈六"：一名布商，殁年四十七；一名脚夫，殁年四十六。同年同月先后身故。生死簿上只勾了一条"陈六"。剩下的那个陈六的家属申诉：凭什么我家的陈六成了没死的人？

【卷面材料（共7条）】
1.【文书】生死簿勾录·正文：生死簿载："陈六，殁于七月十二，布商。"墨迹工整。
2.【文书】生死簿页脚复勾：同页页脚小字批注："七月十九复勾'陈六'——脚夫。"纸色与正文同页，两条勾录叠在同一个名字上。
3.【灰迹】布商陈六墓碑：阳间坟砖："陈公六之墓，卒于七月十二。"砖刻与簿录对得上——布商陈六确实死于七月十二。
4.【口述】脚夫陈六口述·一："我七月十二还在城门下等人雇脚！那天热得很，我在茶棚底下躲日头——我死那天是七月十九，发时疫死的。"（说到时疫他的魂焰就发灰，执念泡过的时间，得拿别的东西钉。）
5.【灰迹】县志时疫条：县志载："七月十五起，城东时疫，旬日而止。"时疫始于七月十五——脚夫说"七月十二躲日头"那天，疫还没起来。他记忆的日期能对上吗？对不上。但他死的月份没错。
6.【文书】脚行雇佣流水：脚行流水：七月十二、十三、十四，均有"陈六"受雇记录，工钱照付。七月十五以后再无陈六——脚夫陈六七月十五前后才病例倒下，十九日身故。
7.【口述】脚夫陈六口述·二："跟我同名的那个布商……我知道他。他先死的，死讯传开那天茶棚里都在讲。我还想，陈六死了，人家烧纸别烧错坟头。"
